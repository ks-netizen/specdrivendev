# Spec Driven Development

A Python project following the Spec Driven Development approach, based on the DeepLearning.AI tutorial.

## Overview

This project explores spec-driven development — writing specifications first, then generating and validating code against those specs.

## Project Structure

```
specdrivendev/
├── specs/          # Specification files
├── src/            # Generated/implemented source code
├── tests/          # Test files
└── README.md
```

## Setup

```bash
python -m venv .venv
source .venv/bin/activate  # On Windows: .venv\Scripts\activate
pip install -r requirements.txt
```
